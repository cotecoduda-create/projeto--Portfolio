# projeto--Portif-lio
Página de Portfólio / Currículo Web de um desenvolvedor. 

# Objetivo

Criar uma página HTML limpa, semântica e funcional que reproduza fielmente os tópicos e a organização do layout do modelo.📝 Requisitos Principais✅ Elementos Essenciais

- # Cabeçalho & Navegação:
  Título principal com o nome/cargo e um menu de navegação com links para as seções (Sobre, Projetos, Contato)
- # Seção "Sobre Mim":
- Foto de perfil formatada com tamanho aproximado de 150px de altura x 150px de largura.
- Texto de apresentação e lista com Minhas Habilidades.

# Seção "Meus Projetos":

- Tabela organizada contendo 4 colunas: Projeto, Tecnologias, Status e Link (com hiperlink funcional).
  
# Seção "Entre em Contato":
- Formulário envolto em um <fieldset> (com o título "Dados do Contato").
- Campos de entrada para Nome, Email, menu suspenso <select> para Assunto e área de texto <textarea> para Mensagem.
- Botão de envio do formulário.
- Rodapé (<footer>):
- Direitos autorais com caractere especial (&copy;), e-mail e telefone de contato.

# Especificações Técnicas
- Estrutura: HTML5 puro e semântico (use <header>, <nav>, <main>, <section>, <table>, <fieldset>, <footer>).
- Imagem: Foto de perfil configurada com width="150" e height="150".
- Navegação: Links internos (âncoras href="#id") apontando para as respectivas seções da página.
- Formulário: Todos os campos com seus respectivos <label> devidamente vinculados.
